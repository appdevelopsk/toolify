## Outreach sequence (manual, opt-in, no spam)
Week 1: submit one genuinely useful individual tool to appropriate directories after checking each directory's submission policy; share two demonstrations on owned social channels; ask 5 relevant users for usability feedback.
Week 2: publish four problem-first examples (e.g. JSON formatting, time zones, unit-price comparison, image sizing) with screenshots and directly linked tools; prioritize English, Spanish, Brazilian Portuguese.
Week 3: repeat only formats with verified **engaged users** and meaningful tool interactions; translate top performers after language review.
Week 4: pitch two niche newsletters or resource curators with a specific tool-use case and transparent project disclosure; review acquisition quality.

## SEO / distribution release gates
1. Verify each localized canonical and hreflang points to a crawlable page with matching content.
2. Verify indexable tool pages are present in sitemap.xml, not noindex, return HTTP 200, and have unique titles, visible guidance, and useful results.
3. Ensure no language variant with partial or incorrect translation is promoted.
4. Share only pages that work on mobile and meet basic Core Web Vitals.
5. Post to communities only when self-promotion is allowed; never buy backlinks, mass-post identical copy, or manufacture testimonials.

## Measurement (weekly, per locale and landing page)
- Search Console: impressions, **organic clicks**, CTR, average position, query and country.
- GA4: engaged sessions, engaged users, calculate events, copy_result, first-user channel / session source.
- Outcome KPIs: real organic users, tool-use / engaged-user rate, 7-day return usage, newsletter opt-ins where consented.
- Exclude suspicious bot patterns using server logs and GA4 traffic quality; annotate false-positive risk. Do **not** treat raw pageviews as human reach.
- Tag owned promotions with UTM: utm_source=<platform>&utm_medium=social&utm_campaign=global_awareness_202611; never use UTMs for organic search links.
- Baseline: previous 28 days; evaluation: next 28 days; segment by locale and landing page. Do not state improvement without comparison data.

## Priority
1. Developer text tools: clear intent, shareable utility, fast completion.
2. International conversion tasks: time-zone / metric-imperial / unit price.
3. Image resizer: privacy-focused use case, demonstrate without overstating file-handling guarantees.
4. Software directory: market only available products; never promote 'coming soon' as shipped.

Owner action required: publishing to external communities, collecting permissioned user feedback, and running deployment or analytics authorization, where applicable.
